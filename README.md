# Simferopol — Living City

A from-scratch Roblox city simulation project.

## Development approach

- Roblox Studio is the runtime and visual editor.
- Rojo synchronizes source files from this repository into Roblox Studio.
- GitHub stores the source of truth and the history of changes.
- The city simulation, factions, civilians, traffic, and persistent-world systems will be developed as our own systems.

## First setup

1. Install Roblox Studio.
2. Install the Rojo command-line tool and the Rojo Studio plugin.
3. Clone this repository to the development computer.
4. From the repository folder, run `rojo serve`.
5. In Roblox Studio, open the Rojo plugin and connect to the running server.
6. Press Play to test the project.

See the official Rojo documentation: https://rojo.space/docs/

## Current milestone

Project scaffold only. No city map, NPC simulation, factions, or persistent-world logic has been implemented yet.
